# Interview Ready

A React interview-preparation app with practical do-and-avoid guidance, an
eight-moment interview walkthrough, an eight-question quiz, and STAR answer
practice. The frontend is integrated with the Base44 Vite plugin. It does not
require sign-in or a backend to use.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Build the production frontend with
`npm run build`.

`preview.html` is a separate preview of the repository's artwork assets.
